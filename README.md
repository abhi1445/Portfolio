# Abhishek Patil — Personal Portfolio

Customized React + Vite portfolio based on the provided CV.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Customize
Edit `src/data/portfolio.js` for your information. The uploaded CV is included as `public/resume.pdf`. GitHub, LinkedIn and project URLs are placeholders because those URLs were not supplied in the CV.

## Deploy to Vercel
Push to GitHub, import the repository in Vercel, use `npm run build`, and deploy the generated `dist` folder.
